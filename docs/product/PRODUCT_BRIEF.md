# Продуктовый бриф: Умный туризм + Pay Compass

Документ для обсуждений с **Grok** / Cloud Agent на ветке монорепо. Обновляйте при смене приоритетов.

## North Star

Помогаем русскоязычным путешественникам **экономить и не ошибаться**: билеты, маршруты, оплата за границей — с прозрачными источниками и без скрытых комиссий «посредника».

## Две поверхности одного бренда

1. **Лендинг** (`landing/`) — «Умный туризм»: контент, калькулятор скрытых сборов агрегаторов vs прямых покупок, воронка в Telegram. Username бота берётся из `BOT_USERNAME`, в вёрстке не зашит.
2. **Telegram Mini App** (`miniapp/`) — основной интерфейс: онбординг, поездка, справочник по 6 странам, профиль. Факты из `database/data/countries.json`. Бот в чате только зовёт в приложение и шлёт уведомления со ссылкой на экран.

## Аудитория

- Самостоятельные путешественники, лоукостеры, стыковки, Турция/ОАЭ/…  
- Нужны: доверие, актуальность, «что работает сейчас», не продажа карт.

## Монетизация (бот)

- Запуск бесплатный: все 6 стран открыты, лимита на 7 дней нет, Stars не продаются.
- Партнёрские ссылки трансфера, eSIM и страховки — Travelpayouts, маркер `765617`, готовая короткая ссылка в `config/partners.json`.

## Монетизация (лендинг)

- Консультации / Telegram-воронка (контент → диалог).

## Единый Supabase

Одна БД: пользователи бота, FSM, страны, источники, health скraper’ов. Лендинг **без** отдельного Postgres — только static или Vercel.

## Roadmap (черновик для обсуждения с Grok)

| Приоритет | Идея | Зависимости |
|-----------|------|-------------|
| P0 | Монорепо + один Supabase | миграции, секреты, деплой |
| P1 | Связка лендинг ↔ бот (UTM, deep link «оплата в …») | продуктовый copy, `/start` payload |
| P1 | Flight Navigator: калькулятор на лендинге ↔ данные бота | API или shared config |
| P2 | Контент-пайплайн: статьи лендинга из verified facts | `knowledge_base`, редакторский процесс |
| P2 | Алерты премиум: Telethon + RSS + Crawlee | scrapers, `source_health` |
