# Лендинг «Умный туризм»

Источник: репозиторий `smart-travel-landing`, перенесён в монорепо **flight-navigator**.

- Локально: открыть `index.html` в браузере.
- Прод: Vercel отдаёт этот файл на `/` (см. корневой `vercel.json`).
- Альтернатива: Supabase Storage в **том же** project, что и бот — [`../docs/supabase-landing-hosting.md`](../docs/supabase-landing-hosting.md).
